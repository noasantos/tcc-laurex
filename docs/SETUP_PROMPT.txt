Quero instalar o Laura Workspace neste computador para usar com a minha conversa no Codex LOCAL. Repositório público: https://github.com/noasantos/tcc-laurex. Clone por HTTPS sem pedir login, token ou acesso ao GitHub. Preserve conversas, documentos, banco, histórico e alterações existentes. Não configure túnel, servidor público ou integração com o ChatGPT web: o MCP deve ser um processo stdio local iniciado pelo próprio Codex.

1. Localize uma instalação existente antes de clonar. Leia AGENTS.md, README.md e docs/OPERATING_MODEL.md. Verifique Node.js compatível e Codex local. Se o comando codex não estiver disponível, localize a CLI do aplicativo instalado ou instale a CLI oficial @openai/codex. Não altere meu login nem solicite segredos na conversa.
2. Execute npm ci, npm run build, npm test e npm run mcp:poc. Para este workspace autorizo o acesso MCP local de leitura e escrita: execute npm run assistant:connect -- --allow-local-write. O script registra laura-workspace com caminhos absolutos e pasta de dados fora do checkout, valida uma leitura real e preserva conexões de outros projetos. Não edite o banco diretamente nem contorne aprovação local.
3. Execute node scripts/launch.cjs. Verifique o site local. O servidor continua rodando sem manter o terminal aberto; nas próximas vezes posso usar Abrir-Laura.cmd ou Abrir-Laura.command, ou pedir ao Codex para chamar ensure_workspace_running.
4. Se esta conversa do Codex já estava aberta durante o registro e não recebeu as ferramentas, peça apenas que eu feche e reabra o Codex e retome a mesma conversa. Não crie uma conversa ou projeto substituto. O registro de configuração não comprova que esta sessão já carregou as ferramentas.
5. Pela conversa local, teste get_project_info e get_workspace_runtime. Confirme o projeto antes de escrever. Testes de escrita usam uma pasta de dados temporária; não crie lixo no meu TCC. Revisões de texto existente são propostas e exigem aprovação na interface. Comentários não são resolvidos automaticamente.
6. Leia docs/PROJECT_CONTEXT.txt como orientação do workspace. Não alegue ter migrado ou alterado conversas de outro produto. Não é necessário configurar início de sessão ou deixar um túnel rodando: o Codex inicia o MCP quando carrega a conexão local.

Ao terminar, diga o endereço do site, o que foi validado e como retomar. Distinga teste local do protocolo, registro no Codex e ferramentas efetivamente disponíveis nesta conversa. Não declare testes no Windows ou no meu computador sem executá-los.
